## Điểm mạnh

1. **Cấu trúc DDD module-first rõ ràng** — mỗi module đều có 4 layer: domain / application / infrastructure / interfaces.
2. **Repository Pattern + Use Cases** đã tách bạch — controllers chỉ orchestrate.
3. **Domain Entities tự bảo vệ tính bất biến** — dùng `private constructor` + `static create/reconstitute`.
4. **Mappers** đảm bảo domain không biết về Mongoose.
5. **Domain Events + EventBus** đã wire qua `EventEmitter2`.
6. **Custom domain exceptions** trả về HTTP status đúng nghĩa nghiệp vụ.
7. **Swagger** đã setup đầy đủ, có Bearer Auth.
8. **`declare` keyword** trên Mongoose schema fix được TS strict mode.
